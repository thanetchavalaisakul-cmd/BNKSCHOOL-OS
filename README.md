## PA workflow
1. ครูตั้งค่า **ข้อมูลส่วนตัวสำหรับเอกสาร PA** ของปีงบประมาณนั้น
2. ครูส่ง PA ต้นปี: PA 1 หน้า หรือ PA ฉบับเต็ม
3. ครูส่งรายงานผล PA ปลายปี
4. กรรมการ PA 3 คนประเมิน PA2 ผ่าน Rubric 60 + 40
5. เมื่อ PA2 ครบ 3/3 ระบบเปิด PA3 และสร้างแบบ PA 3/ส จากผลจริงอัตโนมัติ

## ข้อมูลส่วนตัวสำหรับเอกสาร PA
ครู/หัวหน้ากลุ่มงานที่เป็นผู้ส่ง PA มีการ์ดตั้งค่าของตนเองต่อปีงบประมาณ:
- รับเงินเดือนในอันดับ ครูผู้ช่วย / คศ.1 - คศ.5
- อัตราเงินเดือน
- วันที่อัตรานี้มีผล (ถ้ามี)
- อนุญาตให้ PA ใช้ลายเซ็นหลักอัตโนมัติในปีนั้น

ข้อมูลเงินเดือนไม่เก็บเป็นค่ากลางเดียว แต่ผูกกับปีงบประมาณ และเมื่อรายงานผลถูกส่งจะเก็บ Snapshot เพื่อให้ PA3 ปีเก่าไม่เปลี่ยนตามเงินเดือนปีใหม่

## ลายเซ็นครู
v5.10.0 **ไม่สร้างระบบลายเซ็นครูซ้ำ** แต่ใช้ระบบกลางของ BNK School OS:
- `signatures`
- `user_signature_preferences`
- หน้า `ลายเซ็นของฉัน`

Auto Sign สำหรับ PA ต้องมีทั้ง:
1. ลายเซ็นหลัก + เปิด Auto Sign กลาง
2. เปิด “อนุญาตให้ระบบ PA ใช้ลายเซ็นของฉันอัตโนมัติ” สำหรับปีงบประมาณนั้น

เมื่อครบเงื่อนไข:
- PA 1 หน้าที่ระบบสร้าง: ลงชื่อเมื่อส่ง
- รายงานผล PA: ลงชื่อผู้รายงานผลเมื่อส่ง
- PA ฉบับเต็มที่อัปโหลด: ไม่แก้/ประทับไฟล์ต้นฉบับ
- PA3: ไม่เพิ่มลายเซ็นครู เพราะแบบ PA3 ใช้ลายเซ็นกรรมการตาม workflow PA2
